# Легенды Тайцзи II

Лендинг-регистрация на фестиваль (19 декабря, организатор — [Академия Cheng Long](https://taijipro.com/)).
Next.js (App Router), бэкенд — Directual.

## Структура

- `app/page.tsx` — лендинг, пререндерится статически
- `app/registration-form.tsx` — форма регистрации (клиентский компонент)
- `app/success/page.tsx`, `app/fail/page.tsx` — куда платёжка возвращает после оплаты: «Оплата прошла» /
  «Оплата не прошла» со ссылкой обратно на форму (`noindex`). Общий каркас — `app/pay-screen.tsx`
- `app/venue-info.tsx` — дата, адрес и как добраться — общий блок для лендинга и `/success`
- `app/api/register/route.ts` — прокси: валидирует заявку и шлёт в вебхук Directual
- `lib/registration.ts` — общая схема и валидация заявки (клиент + сервер)
- `lib/email.ts` — проверка почты: понятная причина ошибки (клиент + сервер) и подсказка
  при опечатке в популярном домене или русской раскладке (только форма: один раз останавливает отправку,
  повторное нажатие — «адрес верный»)
- `lib/directual.ts` — работа с Directual (только сервер)
- `assets/brand/`, `public/brand/` — фирменный стиль, вырезан из PDF пресс-волла: пионы, логотип, заголовок, слоган, плашка
- `lib/brand-glyphs.ts` + `app/brand-text.tsx` — заголовки разделов фирменным шрифтом (в PDF он в кривых,
  поэтому есть только буквы из заголовка и слогана: нет М, Я, Б, Ж, Х, Э, Щ, цифр)

В заявке приходит `amount` — сумма к оплате в рублях. Считается на сервере в `lib/registration.ts`
(зритель — 1 000 ₽, спортсмен — 1 000 ₽ за каждую форму), значение с клиента игнорируется.

Вебхук отвечает `{ paymentNeeded, paymentURL }` (в корне или в `result`):
если оплата нужна — редирект на `paymentURL`, иначе экран «Спасибо».
URL возврата из платёжки (настраиваются в Directual / платёжке): успех — `https://legendsoftaichi.ru/success`,
неудача — `https://legendsoftaichi.ru/fail`.

## Запуск

```bash
cp .env.example .env.local  # и подставить URL вебхука
npm install
npm run dev
```
